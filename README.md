# Photo Gallery

A simple photo gallery app built with React, Vite, and Tailwind CSS.

## Features
- Fetches 30 photos from the Picsum Photos API on load
- Search photos by author name in real time
- Mark photos as favourites (persists after page refresh)

## Tech
- React + Vite
- Tailwind CSS
- Custom hook for data fetching
- useReducer for favourites state

## Run locally
npm install
npm run dev
